# FoodieHub — Restaurant Website

A responsive restaurant website project built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive homepage, menu, about, reviews and contact sections
- Menu category filters and dish search
- Shopping cart with quantity controls and subtotal
- Cart saved in browser localStorage
- Demo checkout form (no real payment or delivery)
- Table reservation form (front-end demo)
- Mobile navigation

## Run locally
1. Download and extract `foodiehub-restaurant.zip`.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

No build tools or package installation are required.

## Upload to GitHub
1. Sign in at https://github.com and create a **New repository**.
2. Name it `foodiehub-restaurant` and create the repository.
3. In the repository choose **Add file → Upload files**.
4. Upload `index.html`, `style.css`, `script.js`, and `README.md` (or drag the extracted project files).
5. Click **Commit changes**.

### Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then Save.
4. Wait for deployment; GitHub will show your website URL in the Pages section.

## Important project note
This is a front-end demonstration. Orders, payments, reservations and customer details are not sent to a restaurant server. The checkout and reservation actions show demo confirmations in the browser. A production system needs a secure backend, database, authentication, and a payment provider.
